# Pramod Travels Website

## 📌 Description
A responsive travel agency website built using HTML, CSS, and JavaScript.
The website provides travel information, contact details, and booking inquiry options.

## 🌍 Live Demo
https://pramod-travels.netlify.app/

## ✨ Features
- Responsive design
- Travel packages section
- Contact and inquiry details
- Clean and professional UI

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 🚀 How to Run
Open `index.html` in a browser.
